# 02-技术架构与目录结构

## 技术栈

### 小程序端

- 微信原生小程序。
- WXML / WXSS / JavaScript。
- 使用 `wx.request` 调用后端 API。
- 使用 `wx.setStorageSync` 保存 token 和用户信息。
- 使用本地 `miniprogram/static/` 保存运行所需静态素材。

### 后端

- Node.js。
- Express。
- MySQL。
- `mysql2`。
- `jsonwebtoken`。
- `bcryptjs`。
- `multer`。

### 后台管理

- Vue 3。
- Vite。
- Element Plus。
- Axios。
- Vue Router。

### 数据库

- MySQL。
- `database/init.sql` 负责建表。
- `database/seed.sql` 负责导入测试数据。

以上结构是后续开发目标。本准备阶段只创建 `server/`、`admin/`、`miniprogram/`、`database/` 空目录，不初始化项目、不安装依赖。

## 本地端口草案

- 后端 API：`http://localhost:3000`。
- 后台管理：`http://localhost:5173`。
- 小程序接口 baseURL：开发阶段指向 `http://localhost:3000/api`。

## 图片上传策略

- 上传接口保存文件到 `server/uploads/`。
- 数据库只保存图片 URL，不保存图片二进制。
- 后端静态暴露 `/uploads/*`。
- 小程序静态素材放在 `miniprogram/static/`，业务上传图片走 `/uploads/*`。

## 鉴权策略

- 普通用户登录成功后返回普通用户 token。
- 管理员登录成功后返回管理员 token。
- 普通用户接口使用用户 token。
- 管理端接口使用管理员 token。
- 未登录用户可以访问公开浏览接口。

## 开发顺序

1. 先写数据库脚本。
2. 再写后端 API。
3. 再写后台管理。
4. 再写小程序。
5. 最后联调验收。
