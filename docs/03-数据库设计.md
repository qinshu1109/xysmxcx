# 03-数据库设计

本文件冻结数据库表和字段语义。后续编写 `database/init.sql` 和 `database/seed.sql` 时必须以本文件为准。

## 表清单

1. `users`：普通同学用户。
2. `admin_users`：后台管理员。
3. `cats`：校园猫咪档案。
4. `help_posts`：求助领养信息。
5. `help_post_images`：求助领养配图。
6. `comments`：评论。
7. `banners`：首页轮播图。
8. `app_configs`：平台基础配置。

## users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint pk auto_increment | 用户编号 |
| username | varchar(50) unique not null | 用户名 |
| password_hash | varchar(255) not null | 加密密码 |
| nickname | varchar(50) not null | 昵称 |
| avatar | varchar(255) null | 头像 |
| role | enum('user','admin') not null default 'user' | 用户角色，普通用户或可登录后台的管理员用户 |
| created_at | datetime not null | 注册时间 |
| updated_at | datetime not null | 更新时间 |

## 种子数据要求

`database/seed.sql` 后续至少应包含：

- 1 个管理员账号：`admin / 123456`。
- 至少 2 个普通用户账号，`role = 'user'`。
- 可包含 1 个 `users.role = 'admin'` 的测试账号，用于验证普通用户提升为管理员后可登录后台。
- 6 只猫咪示例，至少包含“小白”“小花”“橘子”。
- 6 条求助领养信息，覆盖不同类型和状态。
- 猫咪详情评论和求助领养详情评论。
- 首页轮播图。
- 平台名称、首页文案、统计文案等基础配置。
