# 07-素材接入规范

本文件定义素材来源、目标路径和使用规则。后续开发不得让 Codex 随机选择素材。

## 素材来源

只使用处理版素材：

```text
C:\Obsidian\项目\校园流浪猫驿站系统\校园拾喵驿站_素材处理版
```

以下目录默认只读，不修改：

```text
C:\Obsidian\项目\校园流浪猫驿站系统\素材
C:\Obsidian\项目\校园流浪猫驿站系统\效果图
C:\Obsidian\项目\校园流浪猫驿站系统\校园拾喵驿站_素材处理版
C:\Obsidian\项目\校园流浪猫驿站系统\首页素材
```

`首页素材/` 是首页专项成品素材目录，允许作为只读来源复制到小程序 `static/home/`，不得在原目录内覆盖、删除或重新生成文件。

## 数据库图片路径规则

`database/seed.sql` 中的图片路径必须使用复制后的目标路径，例如：

```text
/static/cats/cat_xiaobai_thumb.webp
/static/banner/banner_home_hero.webp
/static/mascot/mascot_default_avatar.png
```

上传图片路径使用：

```text
/uploads/<filename>
```

## 使用原则

- 正式图标优先使用 SVG。
- `app.json` 原生 TabBar 使用 PNG 图标，优先使用 `/static/icons/tabbar/` 下的独立 PNG，不直接引用图标表。
- Banner 和猫咪照片优先使用 WebP。
- 透明装饰和吉祥物使用 PNG。
- 后台管理系统优先使用 Element Plus 图标，不强依赖项目图片素材。
- 卡片、搜索框、按钮、标签、阴影、圆角、TabBar 文字由 WXML/WXSS 或 Vue/CSS 实现。
- 小程序页面实现、视觉复刻或素材接入前，先按 `docs/11-小程序前端一次性完成度门禁.md` 填清素材映射、裁剪边界和验收口径。

## 页面专属素材包优先级

页面级复刻和截图还原时，素材源优先级必须是：

1. 当前页面专属已解压素材包。
2. 当前页面专属素材包中的 `manifest`、`README`、`pixel spec`。
3. 当前页面专属素材包压缩包。
4. 用户当前明确指定的截图或效果图。
5. 通用处理版素材。
6. 原始效果图 fallback。

进入下一层 fallback 前，必须先确认上一层明确不存在、不可读、缺少目标文件，或用户明确批准。不得在未检查页面专属素材包的情况下直接使用效果图 fallback。

## 裁剪和路径规则

- 裁剪前必须确认源图来自权威素材源，记录源图相对路径、实际尺寸、裁剪区域来源和输出尺寸。
- 源图尺寸与裁剪参数不匹配时必须停止。
- 裁剪框来自假设而不是标注时必须停止并要求确认。
- 文档、素材映射、操作日志和最终报告中不得新增本机绝对路径。
- 小程序运行时图片路径只允许写项目内运行路径，例如 `/static/home/`、`/static/cats/` 或接口返回路径。
