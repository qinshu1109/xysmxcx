# 06-后台管理规格

本文件冻结 Vue 后台管理系统的路由、模块、表格字段、操作和接口。

后台设计按 `web-admin-app-contract` 原则执行：先定义路由、表格、筛选、表单、权限、状态，再实现页面。

## 后台路由

| 页面 | 路径 | 功能 | 接口 |
|---|---|---|---|
| 管理员登录 | `/login` | 管理员登录 | `POST /admin/auth/login` |
| 后台首页 | `/dashboard` | 数据统计 | `GET /admin/dashboard` |
| 猫咪管理 | `/cats` | 猫咪 CRUD | `/admin/cats` |
| 求助领养管理 | `/help-posts` | 求助领养 CRUD 和状态修改 | `/admin/help-posts` |
| 评论管理 | `/comments` | 评论查询和删除 | `/admin/comments` |
| 用户管理 | `/users` | 用户查询、编辑、删除 | `/admin/users` |
| 轮播图管理 | `/banners` | 首页轮播图 CRUD | `/admin/banners` |
| 基础配置 | `/configs` | 平台名称、首页文案配置 | `/admin/configs` |

## 后台外壳

- 登录页不显示侧边栏。
- 登录后显示侧边栏、顶栏、内容区。
- 顶栏显示管理员昵称和退出登录。
- 未登录访问后台业务路由时跳转 `/login`。
- 普通用户 token 不允许访问管理端接口。
- 管理员登录支持内置 `admin_users` 与 `users.role = admin` 两类来源。

## 通用 UI 状态

每个列表页必须实现：

- `loading`：表格加载中。
- `ready`：正常展示。
- `empty`：无数据。
- `error`：接口失败。

每个表单弹窗必须实现：

- 提交中禁用按钮。
- 提交失败展示错误信息。
- 提交成功关闭弹窗并刷新列表。

## 基础配置

- `platform_name`：平台名称。

- 编辑配置值。

## 权限规则

- 只有管理员可以进入后台。
- 后台可将普通用户设置为管理员。
- `users.role = admin` 的用户可登录后台，`users.role = user` 不能登录后台。
- 后台不区分多级管理员权限。
- 删除操作需要二次确认。
- 接口返回 401 时清空管理员 token 并跳转登录页。
- 接口返回 403 时显示无权限提示。
