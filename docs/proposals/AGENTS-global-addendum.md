# 全局 AGENTS 规则补充提案

当前环境未发现可写全局 AGENTS.md，此文件为建议合并内容。

## 小程序页面复刻通用规则

### 先发现项目根与素材源

- 页面复刻前必须先确认当前工作区根、小程序源码根、目标页面路径、可写范围和禁止修改范围。
- 必须先列出页面专属素材包、素材包说明文件、运行素材目录和参考图来源。
- 没有完成发现，不允许写页面代码、复制素材、裁剪图片或生成图片。

### prompt 路径不能机械执行

- prompt 中的候选路径只能作为线索，不是行动清单。
- 用户当前明确上下文优先于旧 prompt fallback。
- 若候选路径与当前工作区发现结果冲突，必须先停止并报告差异。

### 禁止本机绝对路径进入项目文档

- AGENTS、门禁、prompt、项目文档、操作日志和最终报告中不得新增本机绝对路径。
- 用户给出的本机路径必须转译成路径角色，例如“当前工作区根”“小程序源码根”“页面专属素材包”“运行素材目录”。

### fallback 必须受控

- 页面级素材源优先级是：页面专属已解压素材包、素材包说明文件、素材包压缩包、用户当前指定截图或效果图、通用处理版素材、原始效果图 fallback。
- 只有前一层明确不存在、不可读、缺少目标文件，或用户明确批准时，才允许进入下一层。

### 裁剪前必须校验源图

- 裁剪前必须确认源图来自权威素材源。
- 必须记录源图相对路径、实际尺寸、裁剪框来源和输出尺寸。
- 源图尺寸与裁剪参数不匹配时必须停止。
- 裁剪框来自假设而不是标注时必须停止并要求确认。

### 未验证不能写成已通过

- 静态检查通过不能写成视觉通过。
- 未打开开发者工具不能写成 DevTools 预览通过。
- 未做真机检查不能写成真机通过。
- mock 展示不能写成真实后端或数据库联调通过。
