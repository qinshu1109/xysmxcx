# 04-接口契约

本文件冻结前后端接口语义。后续 `server/`、`admin/`、`miniprogram/` 都必须按本文件实现。

## 通用约定

### Base URL

```text
http://localhost:3000/api
```

### 通用成功返回

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 通用失败返回

```json
{
  "code": 400,
  "message": "错误信息",
  "data": null
}
```

### 鉴权

- 公开接口不需要 token。
- 普通用户接口需要 `Authorization: Bearer <userToken>`，`users.role = user/admin` 的登录用户都可访问普通用户接口。
- 管理员接口需要 `Authorization: Bearer <adminToken>`。
- `/api/admin/*` 除登录外只接受管理员 token，普通用户 token 不允许访问。

### 分页返回

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 10
}
```

## 同学端接口

### 注册

`POST /auth/register`

请求：

```json
{
  "username": "cat_user01",
  "nickname": "爱猫同学",
  "password": "123456",
  "confirmPassword": "123456"
}
```

注册成功用户 `role` 固定为 `user`，前端提交的角色字段会被忽略。

### 登录

`POST /auth/login`

请求：

```json
{
  "username": "cat_user01",
  "password": "123456"
}
```

响应 `data`：

```json
{
  "token": "user-token",
  "user": {
    "id": 1,
    "username": "cat_user01",
    "nickname": "爱猫同学",
    "avatar": "/static/mascot/mascot_default_avatar.png",
    "role": "user"
  }
}
```

### 首页

`GET /home`

响应 `data` 包含：

- `configs`：平台名称、首页文案。
- `banners`：可见轮播图。
- `stats`：猫咪数量、求助信息数量、成功领养数量。
- `latestHelpPosts`：最新求助领养信息。
- `recommendedCats`：推荐猫咪。

### 猫咪列表

`GET /cats?keyword=&filter=&page=&pageSize=`

`filter` 可选：

- `all`
- `adoptable`
- `neutered`
- `attention`
- `healthy`

### 猫咪详情

`GET /cats/:id`

响应 `data` 包含猫咪完整信息和基础统计，不直接内嵌评论列表；评论列表通过评论接口读取。

### 求助领养列表

`GET /help-posts?keyword=&type=&status=&page=&pageSize=`

### 求助领养详情

`GET /help-posts/:id`

联系方式返回时后端应提供脱敏字段：

```json
{
  "contactPhoneMasked": "138****1234"
}
```

### 发布求助领养

`POST /help-posts`

需要普通用户 token。

请求：

```json
{
  "title": "小猫受伤",
  "type": "injury",
  "description": "在图书馆附近发现一只小猫腿部疑似受伤",
  "location": "图书馆东门",
  "contactPhone": "13812341234",
  "images": ["/uploads/help-1.jpg"]
}
```

约束：

- 标题最多 10 个字。
- 描述最多 200 个字。
- 图片最多 3 张。

### 上传图片

`POST /upload`

需要普通用户 token 或管理员 token。

表单字段：

- `file`

响应 `data`：

```json
{
  "url": "/uploads/example.jpg"
}
```

### 评论列表

`GET /comments?targetType=cat&targetId=1&page=&pageSize=`

`targetType` 可选：

- `cat`
- `help_post`

### 发表评论

`POST /comments`

需要普通用户 token。

请求：

```json
{
  "targetType": "cat",
  "targetId": 1,
  "content": "今天在食堂附近看到了它"
}
```

### 我的资料

`GET /me/profile`

需要普通用户 token。用于小程序刷新当前登录用户的最新昵称、头像和角色。

响应 `data`：

```json
{
  "id": 1,
  "username": "cat_user01",
  "nickname": "爱猫同学",
  "avatar": "/static/mine/mine_default_user_avatar.png",
  "role": "admin"
}
```

### 我的发布

`GET /me/help-posts?status=&page=&pageSize=`

需要普通用户 token。

### 我的评论

`GET /me/comments?page=&pageSize=`

需要普通用户 token。

### 删除我的评论

`DELETE /me/comments/:id`

需要普通用户 token。只能删除当前登录用户自己的评论，后端删除条件必须包含 `user_id`。

响应 `data`：

```json
{
  "id": 1
}
```

## 管理端接口

所有管理端接口除登录外均需要管理员 token。

### 管理员登录

`POST /admin/auth/login`

登录时先匹配内置 `admin_users`，如未找到再匹配 `users.role = 'admin'` 的用户。`users.role = 'user'` 不允许登录后台。

请求：

```json
{
  "username": "admin",
  "password": "123456"
}
```

响应 `data`：

```json
{
  "token": "admin-token",
  "admin": {
    "id": 1,
    "username": "admin",
    "nickname": "驿站管理员",
    "role": "admin",
    "source": "admin_user"
  }
}
```

### 后台首页

`GET /admin/dashboard`

响应 `data` 包含：

- 用户数量。
- 猫咪数量。
- 求助领养数量。
- 待处理求助数量。
- 评论数量。
- 最近求助领养。
- 最近评论。

### 猫咪管理

- `GET /admin/cats?keyword=&page=&pageSize=`
- `POST /admin/cats`
- `PUT /admin/cats/:id`
- `DELETE /admin/cats/:id`

### 求助领养管理

- `GET /admin/help-posts?keyword=&type=&status=&page=&pageSize=`
- `POST /admin/help-posts`
- `PUT /admin/help-posts/:id`
- `PATCH /admin/help-posts/:id/status`
- `DELETE /admin/help-posts/:id`

状态修改请求：

```json
{
  "status": "processing"
}
```

### 评论管理

- `GET /admin/comments?targetType=&keyword=&page=&pageSize=`
- `DELETE /admin/comments/:id`

### 用户管理

- `GET /admin/users?keyword=&page=&pageSize=`
- `PUT /admin/users/:id`
- `DELETE /admin/users/:id`

列表返回用户 `role`。编辑用户仅支持更新：

```json
{
  "nickname": "爱猫同学",
  "avatar": "/static/mine/mine_default_user_avatar.png",
  "role": "admin"
}
```

`role` 仅允许 `user`、`admin`。

### 轮播图管理

- `GET /admin/banners`
- `POST /admin/banners`
- `PUT /admin/banners/:id`
- `DELETE /admin/banners/:id`

### 基础配置

- `GET /admin/configs`
- `PUT /admin/configs/:key`

配置更新请求：

```json
{
  "configValue": "校园拾喵驿站"
}
```

## 错误码草案

| code | 含义 |
|---|---|
| 0 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或 token 无效 |
| 403 | 无权限 |
| 404 | 数据不存在 |
| 500 | 服务端错误 |
