# 首页像素级复刻失败事故复盘

## 事故标题

首页像素级复刻失败：素材源误判、裁剪偏移、机械 fallback 与多轮返工。

## 背景

首页复刻任务目标是使用页面专属素材包和参考图，尽量还原微信小程序首页视觉。项目已存在 `首页专属裁剪素材包/`，其中包含 `README.md`、`manifest.json`、`home_pixel_spec.md`、`source_home_reference.png` 和 `static/home/` 成品素材。

## 期望结果

- 先读取页面专属素材包说明和清单。
- 以页面专属素材包作为最高优先级来源。
- 在写页面或裁剪前确认素材映射、源图尺寸、裁剪框来源和验收口径。
- 若动态样式多轮无法贴近参考图，应及时升级为模块级素材策略。
- 交付时明确区分静态检查、视觉预览、真机验证和未验证事项。

## 实际结果

- 执行中没有始终把已解压的页面专属素材包作为最高优先级来源。
- 曾机械按照 prompt 候选路径 fallback，绕到效果图 fallback。
- 没有在关键裁剪前先完整读取素材包中的 `README.md`、`manifest.json`、`home_pixel_spec.md`。
- 没有先列出素材包内 source、preview、`static/home/` 文件清单再判断是否已有目标成品。
- 在用户多次反馈不一致后，仍继续使用 WXML/WXSS 局部调整，而不是及时升级到模块级素材策略。

## 影响范围

- 首页复刻返工次数增加。
- 用户需要多次指出同一类问题，包括素材源选择、图标偏心、图标缩放和中部模块不一致。
- 页面视觉验收被拖长，用户体验受到明显伤害。
- 项目规则暴露出素材源优先级、裁剪前置校验和失败升级机制缺失。

## 用户反馈摘要

- 已存在页面专属素材包，不应绕过它。
- 不应反复造轮子或机械 fallback。
- 底部导航文字和图标多轮对齐失败。
- 无偏素材被直接使用后图标变小，说明没有检查透明画布和可见区域。
- 用户明确要求本轮只复盘和固化规则，不继续修页面。

## 时间线

1. 任务进入首页像素级复刻阶段，已存在 `首页专属裁剪素材包/`。
2. 执行中先做动态 WXML/WXSS 首页实现和多轮样式调整。
3. 快捷入口、统计卡片、底部 TabBar 多次出现与参考图不一致。
4. 后续尝试把中部区域裁成模块图时，没有第一时间以页面专属素材包为唯一权威源。
5. 用户指出应优先使用已存在的页面专属裁剪素材包。
6. 进一步处理 TabBar 图标时，先用偏移补丁修透明画布偏心，后又发现无偏素材直接使用会因巨大透明画布导致图标过小。
7. 用户要求停止页面修复，进行深度复盘和规则固化。

## 根因分析

根因不是单个样式值不准，而是页面复刻流程没有被强制化：素材发现、权威源判断、裁剪前校验、失败升级和交付诚实性没有形成不可跳过的闸门。

## 5 Whys 分析

1. 为什么首页复刻多轮失败？
   因为局部 WXML/WXSS 调整被反复使用，而没有及时判断是否应使用模块级素材或重新确认素材源。

2. 为什么继续局部调整？
   因为缺少“两轮不接近即停止”的失败升级规则。

3. 为什么素材源会误判？
   因为执行时把 prompt 中的候选路径当作行动清单，未先从当前工作区发现页面专属素材包。

4. 为什么裁剪会有偏移风险？
   因为裁剪前没有强制校验源图来源、源图尺寸、裁剪框来源和输出尺寸。

5. 为什么规则没有阻止事故？
   现有门禁强调先锁素材和参考图，但没有足够明确地规定页面专属素材包优先级、fallback 审批、Stop-the-line 条件和失败升级机制。

## 直接原因

- 未优先读取和使用 `首页专属裁剪素材包/`。
- 未在裁剪前强制校验源图和裁剪框。
- 同一区域多轮视觉不一致后仍继续局部样式调整。
- 对透明图标只检查居中，未检查可见区域与画布比例。

## 系统性原因

- prompt 中本机路径和候选路径过强，诱发机械执行。
- 项目规则没有明确禁止机械 fallback。
- 门禁没有把“页面专属素材包”定义为第一权威来源。
- 缺少页面几何记录和裁剪报告模板。
- 缺少失败升级和 Stop-the-line 机制。

## 被违反的已有规则

- 门禁中的“一句话原则”：先锁参考、素材、数据状态和验收口径，再写页面。
- 门禁中的素材映射要求：开发前列明源路径、目标路径、图片用途和裁剪边界。
- 门禁中的验收诚实性要求：未执行 DevTools 或真机验收不能写成通过。
- 素材接入规范中的“不得随机选择素材”原则。

## 缺失的规则

- 页面专属素材包优先级。
- prompt 候选路径不能机械执行。
- fallback 必须经审批。
- 裁剪前置校验。
- 两轮样式失败后停止并复盘。
- 页面几何记录强制项。
- 透明图标可见区域和画布比例检查。

## 后续强制规则

- 页面级复刻先读页面专属素材包，再读通用素材。
- 未列出素材包文件清单前不得裁剪、复制素材或写页面。
- 裁剪必须记录源图相对路径、源图尺寸、裁剪框来源和输出尺寸。
- 同一区域连续两轮 WXML/WXSS 调整仍不接近参考图时，停止局部调整。
- 需要 fallback 到原始效果图时，必须先说明风险并等待用户批准。
- 任何最终交付必须区分已完成、已验证、未验证、未执行、当前环境无法确认、仍有风险、下一步。

## Stop-the-line 停止条件

- 找不到页面专属素材包。
- 找不到任务依赖的 `manifest`、`README` 或 `pixel spec`。
- 发现多个候选素材源，无法确定权威来源。
- 源图尺寸与裁剪参数不匹配。
- 裁剪框来自猜测而不是标注。
- 需要 fallback 到效果图但用户没有授权。
- 需要写入本机绝对路径。
- 需要修改超出本轮允许范围的文件。
- 视觉验收必须依赖微信开发者工具截图但当前没有执行截图验证。

## 同类页面复刻最小工作流

1. 确认当前工作区根和小程序源码根。
2. 确认目标页面路径、可写范围和禁止修改范围。
3. 读取项目 AGENTS 和前端门禁。
4. 查找页面专属已解压素材包。
5. 读取素材包 `README`、`manifest`、`pixel spec`。
6. 列出素材包内 source、preview、运行素材和目标成品。
7. 写素材映射和页面几何记录。
8. 若需要裁剪，先做裁剪前置校验。
9. 再写 WXML/WXSS/JS。
10. 做静态检查、截图检查、必要时真机检查。
11. 按交付结论模板报告。

## 可复用检查清单

- 是否已读项目 AGENTS？
- 是否已读前端门禁？
- 是否已确认页面专属素材包？
- 是否已读 `README`、`manifest`、`pixel spec`？
- 是否已列出素材包文件清单？
- 是否已确认目标页面和写入范围？
- 是否已确认禁止修改范围？
- 是否存在多个候选素材源？
- 是否需要 fallback？
- fallback 是否获得用户授权？
- 裁剪源图尺寸是否与预期一致？
- 裁剪框是否来自标注？
- 输出尺寸是否符合预期？
- 是否已经记录未执行的 DevTools、真机或截图 diff？

## 仍有风险

- 后续 prompt 如果继续写本机绝对路径，仍可能诱发机械执行。
- 如果不先读页面专属素材包 `manifest`，仍可能重犯素材源误判。
- 如果没有 DevTools 截图 diff，视觉通过不能确认。
- 如果没有页面几何记录，同类页面复刻仍可能依赖临场猜测。

## 后续行动项

- 先让用户确认本复盘和新增规则。
- 确认后，再进入首页修复或下一页面实现。
- 后续页面复刻前先补页面几何记录。
- 对页面专属素材包建立固定检查清单。
- 对模块级素材裁剪建立裁剪报告。
