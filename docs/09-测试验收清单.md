# 09-测试验收清单

本文件用于后续联调和最终验收。当前准备阶段不执行这些测试。

## 启动验收

1. 启动 MySQL。
2. 执行 `database/init.sql`。
3. 执行 `database/seed.sql`。
4. 启动 `server/`。
5. 启动 `admin/`。
6. 使用微信开发者工具打开 `miniprogram/`。

## 前端门禁验收

- [ ] 小程序页面实现前已读取 `docs/11-小程序前端一次性完成度门禁.md`。
- [ ] 已确认本次页面边界、参考图或素材来源。
- [ ] 已确认素材源路径和小程序目标路径。
- [ ] 已确认完整横幅、猫咪照片、吉祥物、图标的裁剪和透明化边界。
- [ ] 已确认页面使用微信默认导航栏或统一安全导航。
- [ ] 已确认页面引用的 `/static/` 图片均存在。
- [ ] 已确认源码中没有引用 Obsidian 资料目录绝对路径。
- [ ] 已确认 DevTools 预览、真机、截图、后端联调哪些已执行，哪些未执行。

## 测试 9：前后台联动

- [ ] 后台新增猫咪后，小程序猫咪图鉴出现新猫咪。
- [ ] 后台修改求助状态后，小程序求助详情状态变化。
- [ ] 后台删除评论后，小程序详情页评论消失。
- [ ] 后台修改首页轮播图后，小程序首页刷新显示变化。
- [ ] 后台修改平台名称后，小程序首页显示变化。

- [ ] 新增数据真实写入数据库。

- [ ] 删除数据真实删除或软删除数据库记录。
