# 10-运行说明

本项目按 Windows 原生环境交付，不依赖 Docker，不依赖 Linux。

## 环境要求

- Windows 10/11。
- Node.js 18 或更高版本。
- MySQL 8.x Windows 版。
- 微信开发者工具。

检查命令：

```bat
node -v
npm -v
mysql --version
```

## 1. 小白一键启动

客户电脑已安装 Node.js 和 MySQL 后，在项目根目录双击或执行：

```bat
一键启动.bat
```

脚本会自动：

- 检查 `node`、`npm`、`mysql`。
- 如果没有 Node.js，会拉起包内 `runtime/nodejs/` 下的 Windows Node.js 安装包。
- 尝试启动常见 MySQL Windows 服务。
- 自动尝试 MySQL `root` 空密码和 `root / 123456`。
- 首次运行时导入数据库。
- 自动生成 `server/.env`。
- 安装依赖。
- 分别启动后端 API 和后台管理系统。
- 打开 `http://localhost:5173`。

如果客户 MySQL root 密码不是空密码或 `123456`，脚本会提示输入。

重置测试数据：

```bat
一键启动.bat --reset
```

指定 MySQL root 密码：

```bat
一键启动.bat 123456
```

不带 `--reset` 时不会重复导入 `seed.sql`，避免每次启动清空客户测试数据。

## 2. 手动初始化数据库

确认 MySQL 服务已启动后，在项目根目录执行：

```bat
database\import-win.bat
```

默认使用 MySQL 用户 `root`，脚本会提示输入密码。

如果需要指定用户：

```bat
database\import-win.bat your_mysql_user
```

脚本导入：

- `database/init.sql`
- `database/seed.sql`

数据库名：

```text
campus_cat_station
```

导入脚本和 SQL 文件都显式使用 `utf8mb4`，避免中文乱码。

## 3. 手动启动后端

执行：

```bat
server\start-win.bat
```

首次运行会自动复制：

```text
server/.env.example -> server/.env
```

如本机 MySQL 设置了密码，需要编辑 `server/.env`：

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_DATABASE=campus_cat_station
```

后端默认地址：

```text
http://localhost:3000/api
```

健康检查：

```text
http://localhost:3000/api/health
```

## 4. 手动启动后台

另开一个命令行窗口执行：

```bat
admin\start-win.bat
```

后台默认地址：

```text
http://localhost:5173
```

默认后台管理员：

```text
username: admin
password: 123456
```

## 5. 启动小程序

1. 打开微信开发者工具。
2. 导入当前项目。
3. 确认 `project.config.json` 中 `miniprogramRoot` 为 `miniprogram/`。
4. 确认后端 API 已启动。

小程序 API 默认地址：

```text
http://localhost:3000/api
```

默认普通用户：

```text
username: cat_user01
password: 123456
```

默认管理员用户：

```text
username: cat_admin01
password: 123456
```

## 6. 验收顺序

1. `一键启动.bat` 成功，或手动执行数据库、后端、后台三步成功。
2. 访问 `/api/health` 返回正常。
3. 后台可以登录。
4. 微信开发者工具打开小程序，登录普通用户。
5. 后台把普通用户设置为管理员，小程序重新进入“我的”页后显示管理员。

## 不执行

- 不要求 Docker。
- 不要求 Linux。
- 不做线上部署。
