# 05-小程序页面规格

本文件冻结微信小程序同学端页面、路由、接口和状态。

## 页面路由

| 页面 | 路径 | 是否需要登录 | 主要接口 |
|---|---|---:|---|
| 登录页 | `pages/login/index` | 否 | `POST /auth/login` |
| 注册页 | `pages/register/index` | 否 | `POST /auth/register` |
| 首页 | `pages/home/index` | 否 | `GET /home` |
| 猫咪图鉴 | `pages/cats/index` | 否 | `GET /cats` |
| 猫咪详情 | `pages/cat-detail/index` | 否 | `GET /cats/:id`、`GET /comments` |
| 求助领养列表 | `pages/help/index` | 否 | `GET /help-posts` |
| 求助领养详情 | `pages/help-detail/index` | 否 | `GET /help-posts/:id`、`GET /comments` |
| 发布求助领养 | `pages/publish/index` | 是 | `POST /help-posts`、`POST /upload` |
| 我的 | `pages/mine/index` | 否 | 本地登录态、`GET /me/profile`、`GET /me/help-posts`、`GET /me/comments` |
| 我的发布 | `pages/my-posts/index` | 是 | `GET /me/help-posts` |
| 我的评论 | `pages/my-comments/index` | 是 | `GET /me/comments`、`DELETE /me/comments/:id` |

## TabBar

- 首页：`pages/home/index`。
- 猫咪图鉴：`pages/cats/index`。
- 求助领养：`pages/help/index`。
- 我的：`pages/mine/index`。

- 使用微信原生 `app.json` TabBar，不在四个主页面内重复手写固定底栏。
- Tab 页之间统一使用 `wx.switchTab` 切换。
- TabBar 图标使用小程序运行目录 `/static/icons/tabbar/` 下拆分后的 PNG 图标。

## 通用状态

每个请求型页面至少实现：

- `loading`：加载中。
- `ready`：正常展示。
- `empty`：无数据。
- `error`：接口失败。

需要登录的页面在无 token 时跳转登录页。

## 登录页

### 页面数据

- `username`
- `password`

### 交互

- 点击登录调用 `POST /auth/login`。
- 登录成功后保存 token 和用户信息。
- 登录成功后返回上一页；没有上一页时跳转首页。
- 点击注册进入注册页。

## 注册页

### 页面数据

- `username`
- `nickname`
- `password`
- `confirmPassword`

### 交互

- 点击注册调用 `POST /auth/register`。
- 注册成功后跳转登录页。

## 首页

### 使用接口

- `GET /home`

### 页面数据

- `platformName`
- `homeSlogan`
- `banners`
- `stats.catCount`
- `stats.helpPostCount`
- `stats.adoptionSuccessCount`
- `latestHelpPosts`
- `recommendedCats`

### 交互

- 点击 Banner：按 `link_type` 和 `link_target` 跳转。
- 点击“发布求助”：已登录进入发布页，未登录进入登录页。
- 点击最新求助：进入求助领养详情。
- 点击推荐猫咪：进入猫咪详情。

### 空状态

- 无轮播图：显示默认 Banner 区域。
- 无最新求助：显示“暂无求助信息”。
- 无推荐猫咪：显示“暂无推荐猫咪”。

## 猫咪图鉴

### 使用接口

- `GET /cats`

### 页面数据

- `keyword`
- `filter`
- `cats`
- `page`
- `hasMore`

### 筛选项

- 全部：`all`
- 可领养：`adoptable`
- 已绝育：`neutered`
- 需关注：`attention`
- 健康：`healthy`

### 交互

- 输入关键词后搜索猫咪名字或出没地点。
- 切换筛选项重新请求列表。
- 点击猫咪卡片进入猫咪详情。

## 猫咪详情

### 使用接口

- `GET /cats/:id`
- `GET /comments?targetType=cat&targetId=:id`
- `POST /comments`

### 展示内容

- 照片。
- 名字。
- 性别。
- 年龄。
- 毛色。
- 性格。
- 出没地点。
- 健康情况。
- 是否绝育。
- 能否领养。
- 备注。
- 评论列表。

### 交互

- 未登录用户可以查看评论。
- 登录用户可以发表评论。
- 未登录点击发表评论时跳转登录页。

## 求助领养列表

### 使用接口

- `GET /help-posts`

### 页面数据

- `keyword`
- `type`
- `status`
- `posts`
- `page`
- `hasMore`

### 交互

- 按标题、地点搜索。
- 按类型筛选。
- 按状态筛选。
- 点击卡片进入详情。
- 点击发布按钮时，已登录进入发布页，未登录进入登录页。

## 求助领养详情

### 使用接口

- `GET /help-posts/:id`
- `GET /comments?targetType=help_post&targetId=:id`
- `POST /comments`

### 展示内容

- 标题。
- 类型。
- 配图。
- 详细描述。
- 地点。
- 脱敏联系方式。
- 发布人。
- 发布时间。
- 当前状态。
- 处理进度。
- 评论列表。

### 处理进度

- 已提交。
- 处理中。
- 已完成。

## 发布求助领养

### 使用接口

- `POST /upload`
- `POST /help-posts`

### 表单字段

- 信息类型。
- 标题，最多 10 个字。
- 详细描述，最多 200 个字。
- 发生地点。
- 联系方式。
- 图片，最多 3 张。

### 交互

- 未登录无法进入，直接跳转登录页。
- 图片先上传，拿到 URL 后提交表单。
- 发布成功后跳转求助领养详情或列表页。

## 我的

### 未登录状态

展示：

- 默认头像。
- “登录后查看你的发布和评论”。
- 登录按钮。
- 我的发布入口。
- 我的评论入口。
- 关于平台。

未登录点击“我的发布”或“我的评论”时跳转登录页。

### 已登录状态

展示：

- 用户头像。
- 用户昵称。
- 用户账号。
- 用户角色标签：`user` 显示普通用户，`admin` 显示管理员。
- 我的发布数量。
- 我的评论数量。
- 我的发布入口。
- 我的评论入口。
- 管理员用户额外显示“管理员后台”入口，点击后提示在浏览器打开后台管理系统并可复制后台地址。
- 退出登录。

进入“我的”页时调用 `GET /me/profile` 刷新本地用户缓存，避免后台调整角色后继续显示旧角色。

## 我的发布

### 使用接口

- `GET /me/help-posts`

### 筛选项

- 全部。
- 待处理。
- 处理中。
- 已完成。

### 交互

- 点击发布记录进入求助领养详情。

## 我的评论

### 使用接口

- `GET /me/comments`
- `DELETE /me/comments/:id`

### 展示内容

- 评论内容。
- 评论对象。
- 评论时间。
- 查看详情入口。
- 删除入口。

### 交互

- 评论对象为猫咪时，跳转猫咪详情。
- 评论对象为求助领养时，跳转求助领养详情。
- 点击删除前二次确认，只允许删除当前登录用户自己的评论。
