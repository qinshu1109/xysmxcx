# 猫咪图鉴页面几何记录

## 页面结构

页面顺序：

1. 自定义顶部标题：`猫咪图鉴`。
2. 圆角搜索框：左侧使用 `static/cats-page/icon_search.png`。
3. 筛选胶囊：全部、可领养、已绝育、需关注、健康。
4. 双列猫咪卡片：照片、性别角标、名字、出没地点、状态标签。
5. 自定义底部栏：猫咪图鉴选中。

## 搜索框策略

- 使用 WXML / WXSS 实现白色圆角搜索框。
- 搜索图标来自页面专属素材目录。
- 输入后本地过滤猫咪名字和出没地点。

## 筛选胶囊策略

- 胶囊由 WXSS 实现，不裁整图。
- 选中项使用珊瑚红渐变，未选中项为白底浅阴影。
- 筛选值对齐后续 `GET /cats` 语义：`all`、`adoptable`、`neutered`、`attention`、`healthy`。

## 双列卡片策略

- 使用两列 grid。
- 猫咪照片来自 `static/cats-page/`，不透明 JPG。
- 性别角标使用页面专属透明 PNG，覆盖在照片右上角。
- 卡片文字和状态标签由 WXML / WXSS 实现，不做整图。

## 底部栏策略

- 复用首页自定义底部栏的布局思路。
- 本页图标来自 `static/cats-page/`。
- 首页入口跳回 `pages/home/index`。
- 求助领养、我的暂不创建页面，只提示后续页面开发中。

## 仍可能存在的差异

- 本轮未运行微信开发者工具，无法确认最终截图与参考图的一致性。
- 动态 WXML / WXSS 的字体、阴影、行高和真机渲染可能与效果图有细微差异。
- 当前使用页面专属已处理素材包，不重新裁剪效果图。
