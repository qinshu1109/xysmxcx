# 猫咪详情页面几何记录

## 页面结构

页面顺序：

1. 自定义顶部导航：返回按钮和标题 `猫咪详情`。
2. 猫咪大图：复用猫咪图鉴页面的小白照片。
3. 基础信息卡：名字、性别、年龄、毛色、可领养状态。
4. 详情信息卡：性格、出没地点、健康情况、是否绝育、能否领养、备注。
5. 评论卡：三条 mock 评论。
6. 底部评论输入栏。

## 素材策略

- 图标统一来自 `cat_detail_full_assets_pack/icons/trimmed/`。
- 详情主图来自 `cat_detail_full_assets_pack/hero/white_cat_top_hero.jpg`。
- 评论头像来自 `cat_detail_full_assets_pack/comment_avatars/cropped_512/`。
- 小程序运行素材统一放入 `static/cat-detail/`。
- 本轮未重新裁剪效果图。

## 布局策略

- 保持项目当前自定义导航，不手动画系统时间、状态栏或微信胶囊。
- 页面背景使用浅粉橙渐变。
- 主图固定宽高和圆角，卡片使用白底、圆角、轻阴影。
- 详情行使用固定图标盒，文字用 WXML/WXSS 实现。
- 评论输入栏固定底部，并兼容 `env(safe-area-inset-bottom)`。

## 仍可能存在的差异

- 未运行微信开发者工具，无法确认最终截图与参考图一致性。
- 评论头像和详情主图已由完整素材包补齐；仍未做 DevTools 截图复核。
- 字体、阴影、圆角、主图裁切在微信渲染中可能有细微偏差。
