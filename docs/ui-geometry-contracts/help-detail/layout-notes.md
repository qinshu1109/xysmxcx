# 求助详情页几何记录

## 页面结构

- 自定义导航：标题为“求助详情”，左侧返回图标使用页面专属透明素材。
- 顶部主图：使用不透明主图素材，由 WXML/WXSS 控制圆角和显示比例。
- 摘要卡片：猫咪图标、标题、类型标签、发布时间和状态标签由 WXML/WXSS 渲染。
- 情况说明：卡片、标题、正文由 WXML/WXSS 渲染。
- 联系信息：地点、联系方式、发布人三行，图标使用页面专属透明素材。
- 进度卡片：圆点和虚线使用页面专属透明素材，文字由 WXML/WXSS 渲染。
- 志愿者留言：头像使用页面专属透明素材，昵称、角色、时间、内容由 WXML/WXSS 渲染。
- 底部输入栏：固定在底部并兼容安全区，评论图标使用页面专属透明素材。

## 素材策略

- 本页不把整页裁成大图。
- 本页不把卡片、搜索框、输入框、状态标签或文字裁成图片。
- 顶部主图保持不透明，不做透明化。
- 图标、头像、进度线保留真透明 PNG。
- 运行时图片统一放入 `static/help-detail/`。

## 布局策略

- 页面宽度按 750rpx 设计，主体内容宽 686rpx。
- 背景使用顶部粉色到浅色的 CSS 渐变，避免裁整页背景。
- 主图高度暂定 300rpx，使用 `aspectFill`，仍需在 DevTools 中确认猫咪主体是否完整。
- 卡片圆角约 24rpx 到 26rpx，阴影保持轻量。
- 底部评论输入栏使用 fixed 布局，页面内容底部预留空间，避免被遮挡。
