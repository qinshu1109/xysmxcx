# 我的页几何记录

## 页面结构

- 一个页面 `pages/mine/index` 承载未登录和已登录两种状态。
- 未登录状态：顶部柔和背景、透明吉祥物、登录提示、立即登录按钮、三项菜单、底部栏。
- 已登录状态：资料卡、统计卡、三项菜单、底部栏。
- 底部栏使用页面专属图标，“我的”为选中态。

## 素材策略

- 本页不整页裁图。
- 未登录背景和已登录资料卡背景按素材包复制，不重新绘制。
- 吉祥物和图标 sheet 保留真透明 PNG。
- 菜单卡、统计卡、按钮、文字由 WXML/WXSS 实现。
- 运行时图片统一放入 `static/mine/`。

## 布局策略

- 页面宽度按 750rpx 设计，主体内容宽 686rpx。
- 自定义导航沿用当前小程序安全区计算方式。
- 未登录头部背景源图比例为 1448:1086，按 686rpx 宽等比显示应约为 515rpx；禁止压缩为短横幅比例。
- 未登录登录按钮使用正常居中流布局，不使用单点 `margin-left`、负偏移或 transform 硬调。
- 已登录资料卡背景源图比例为 2124:671，按 686rpx 宽等比显示应约为 217rpx；禁止压缩为 180rpx 一类短卡片。
- 已登录统计卡高度约 132rpx。
- 底部栏兼容 `env(safe-area-inset-bottom)`。

## 本轮比例修复记录

- 修复前：`mine_guest_header_bg.png` 被显示为 686rpx × 382rpx，和源图比例不一致，导致未登录顶部区域整体被压扁。
- 修复后：未登录头部区域显示为 686rpx × 515rpx，匹配源图比例。
- 修复前：`mine_profile_card_bg.png` 被显示为 686rpx × 180rpx，和源图比例不一致，导致已登录资料卡偏矮。
- 修复后：已登录资料卡显示为 686rpx × 217rpx，匹配源图比例。
- 修复前：登录按钮使用绝对定位加 `margin-left` 居中，微信按钮默认样式下容易表现为偏移。
- 修复后：登录按钮放入居中 flex 容器，使用 `margin: auto` 居中。

## 已登录头像容器修复记录

- 修复前：用户头像直接作为 `image` 绝对定位在资料卡内，边框、圆角和裁切都挂在图片本身，缺少独立头像容器。
- 问题表现：微信渲染下头像盒子边界不清晰，文字区起点也偏早，视觉上像头像没有被收进容器且压到文字区域。
- 修复后：新增 `profile-avatar-box`，由盒子负责固定尺寸、边框、圆角和 `overflow: hidden` 裁切；头像图片只在盒子内 `100%` 填充。
- 修复后：资料文字区起点从 190rpx 调整到 212rpx，按头像盒子右边界留出稳定间距。

## 已登录资料卡背景白框对齐修复

- 二次排查确认：`mine_profile_card_bg.png` 不是纯背景，素材内部已经包含头像白色圆角占位框。
- 按 686rpx 宽缩放后，白色占位框大致位于卡片内 `x=63..199, y=35..180`。
- 前一次修复仍有问题的原因：头像盒子放在 `left:42rpx`，比素材自带白框偏左，导致右侧白框露出成白色竖条。

- 当前修复：资料文字区起点调整为 `left:224rpx`，避开素材自带头像白框。
