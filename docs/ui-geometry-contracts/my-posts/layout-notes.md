# 我的发布页面几何记录

## 页面结构

1. 自定义顶部导航：返回按钮 + 标题“我的发布”。
2. 筛选胶囊：全部、待处理、处理中、已完成。
3. 发布记录列表：单列白色圆角卡片。
4. 底部鼓励横幅：使用完整素材图，不拆分文字和插画。

## 素材策略

- 权威素材目录：`mypost_page_assets/`。
- 运行素材目录：`static/mypost/`。
- 缩略图和底部横幅只复制到运行目录，不透明化、不重绘。
- `mypost_icon_sheet.png` 是透明图标表，本轮仅在运行目录拆出返回、时间、定位、爪印图标。
- 没有把整页、筛选按钮、卡片文字、状态标签裁成图片。

## 布局策略

- 页面使用自定义导航，延续现有小程序页面的安全区计算。
- 筛选胶囊用 WXML/WXSS 渲染，四项等宽排布。
- 发布卡片使用固定缩略图尺寸，文字区使用弹性布局。
- 状态标签和类型标签用 WXML/WXSS 渲染，便于后续接口数据驱动。
- 点击发布记录跳转到 `pages/help-detail/index`。

- 未做真机验证。
