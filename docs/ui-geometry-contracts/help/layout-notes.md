# 求助领养页面几何记录

## 页面结构

页面顺序：

1. 自定义顶部标题：`求助领养`。
2. 完整 Banner：使用页面专属完整图，不拆文字和按钮。
3. 搜索框：按标题和地点本地过滤。
4. 类型筛选：全部、求助、领养。
5. 状态筛选：全部状态、待处理、处理中、已完成。
6. 求助领养列表卡片。
7. 自定义底部栏：求助领养选中。

## 素材策略

- Banner 和缩略图直接来自 `help_adoption_page_assets/help_adoption_assets/`。
- 图标来自 `icons/help_icon_sheet.png`，按 README 中 4 列 × 2 行顺序拆为单个透明 PNG。
- 小程序运行素材统一放入 `static/help-adoption/`。

## 布局策略

- 保持项目当前自定义导航，不手动画系统时间、状态栏或微信胶囊。
- 页面背景使用浅粉橙渐变。
- Banner 用固定比例容器显示完整素材。
- 列表卡片使用白底、圆角、轻阴影，文字和标签由 WXML/WXSS 实现。
- 底部栏使用页面专属图标并兼容 `env(safe-area-inset-bottom)`。

## 仍可能存在的差异

- 未运行微信开发者工具，无法确认最终截图与参考图一致性。
- 图标由平铺图拆分为 96 × 96 透明 PNG，实际视觉大小仍需 DevTools 复核。
- 动态 WXML / WXSS 的字体、阴影、间距可能与效果图有细微差异。
