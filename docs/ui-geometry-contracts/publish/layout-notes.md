# 发布求助领养页几何记录

## 页面结构

- 自定义导航：标题为“发布求助领养”，左侧返回图标使用页面专属透明素材。
- 顶部提示横幅：使用页面专属完整横幅，不拆字、不透明化、不重绘。
- 表单卡片：信息类型、标题、详细描述、发生地点、联系方式、照片上传区域。
- 底部提示：隐私盾牌图标和保密说明。
- 提交按钮：WXML/WXSS 渲染渐变按钮，不裁成图片。

## 素材策略

- 本页不整页裁图。
- 横幅和上传预览照片保持不透明。
- 图标 sheet 只拆分成透明 PNG 单图标。
- 表单输入框、胶囊、虚线框、按钮、文字都由 WXML/WXSS 实现。
- 运行时图片统一放入 `static/publish/`。

## 布局策略

- 页面宽度按 750rpx 设计，主体内容宽 686rpx。
- 横幅宽 686rpx，高 172rpx。
- 表单卡片宽 686rpx，圆角 28rpx，轻阴影。
- 左侧字段标签宽 150rpx，右侧输入区自适应。
- 上传预览容器宽 462rpx，内含一个上传入口和两个 mock 预览图。
- 内容底部保留安全区，不固定提交按钮，避免遮挡表单。
