# 我的评论页面几何记录

## 页面结构

1. 自定义顶部导航：返回按钮 + 标题“我的评论”。
2. 顶部提示横幅：使用完整素材图，不拆分文字和装饰。
3. 评论记录列表：单列白色圆角卡片。
4. 每张卡片展示评论内容、评论对象、时间、查看详情按钮。

## 素材策略

- 权威素材目录：`mycomments_page_assets/`。
- 运行素材目录：`static/mycomments/`。
- 顶部横幅只复制到运行目录，不透明化、不重绘。
- `mycomments_icon_sheet.png` 和 `mycomments_target_thumb_sheet.png` 均为透明图表，本轮只在运行目录拆分。
- 评论对象缩略图已按 alpha 可见区域重新裁紧，并归一到 256×256 透明居中画布，避免透明空白导致显示偏移。
- 没有把整页、评论卡片、按钮文字裁成图片。

## 布局策略

- 页面使用自定义导航，沿用现有安全区计算。
- 评论内容、对象名称、时间、按钮文字均由 WXML/WXSS 渲染。
- 评论对象小图使用运行目录透明 PNG，放在固定图标盒中。
- 点击“查看详情”时，猫咪对象进入 `pages/cat-detail/index`，求助类对象进入 `pages/help-detail/index`。

## 未验证项

- 未执行微信开发者工具截图对照。
- 未做真机验证。
- 未接入 `GET /me/comments` 后端接口。
- 动态 WXML/WXSS 与效果图仍可能存在细微比例差异，需要 DevTools 截图复核。
