# 00-开发总览

## 项目目标

实现一个本地运行的校园流浪猫救助系统，帮助同学查看校园流浪猫信息、发布求助领养信息、留言交流，并让管理员通过网页后台维护平台内容。

系统包含：

1. 微信小程序同学端。
2. Node.js Express 后端 API。
3. MySQL 数据库。
4. Vue 3 管理员网页后台。

## 项目边界

本项目是本地大作业，不做真实线上业务能力：

- 不做真实微信授权。
- 不做短信验证码。
- 不做地图定位。
- 不做在线支付。
- 不做复杂审核流。
- 不做线上部署。

登录注册只做本地模拟；图片上传只保存到本地 `server/uploads/`；所有业务数据必须真实写入 MySQL。

## 用户角色

### 普通同学

普通同学使用微信小程序，可以：

- 浏览首页。
- 浏览猫咪图鉴。
- 查看猫咪详情。
- 浏览求助领养列表。
- 查看求助领养详情。
- 注册和登录。
- 登录后发布求助领养信息。
- 登录后发表评论。
- 查看我的发布。
- 查看我的评论。
- 退出登录。

### 管理员

管理员使用网页后台，可以：

- 登录后台。
- 管理猫咪信息。
- 管理求助领养信息。
- 管理评论。
- 管理用户。
- 管理首页轮播图。
- 管理平台名称和首页文案等基础配置。

## 系统数据流

```text
微信小程序同学端
        |
        | HTTP API
        v
Node.js Express 后端服务
        |
        | SQL
        v
MySQL 数据库
        ^
        |
        | HTTP API
        |
Vue 3 管理员后台
```

## 核心原则

- 小程序不直接访问数据库。
- 后台管理系统不直接访问数据库。
- 所有业务读写都通过后端 API。
- 后台修改后的轮播图、基础配置、猫咪信息、求助领养信息，必须能被小程序读取到。
- 不使用写死假数据冒充数据库数据。
- 小程序页面实现、视觉复刻和素材接入前，必须先按 `docs/11-小程序前端一次性完成度门禁.md` 确认页面边界、素材映射、图片模式、安全区和验收口径。
