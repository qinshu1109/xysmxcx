# 08-开发任务拆分

后续开发必须按阶段推进。每个 Phase 完成后先验收和 checkpoint，再进入下一阶段。

## Phase 1：数据库与测试数据

### 目标

- 编写 `database/init.sql`。
- 编写 `database/seed.sql`。
- 建表覆盖 `users`、`admin_users`、`cats`、`help_posts`、`help_post_images`、`comments`、`banners`、`app_configs`。
- 测试数据覆盖首页、猫咪图鉴、详情、求助领养列表、我的发布、我的评论。

### 验收

- SQL 可在 MySQL 执行。
- 测试数据包含管理员账号。
- 测试数据包含普通用户账号。
- 测试数据包含“小白”“小花”“橘子”等猫咪。
- 首页轮播图和基础配置来自数据库。
- 图片路径符合 `docs/07-素材接入规范.md`。

## Phase 2：后端 API

### 目标

- 初始化 `server/` Node.js Express 项目。
- 实现 MySQL 连接。
- 实现普通用户注册登录。
- 实现管理员登录。
- 实现首页、猫咪、求助领养、评论、上传、我的页面、后台管理接口。
- 实现普通用户 token 和管理员 token 中间件。

### 验收

- `GET /api/home` 可返回首页数据。
- 普通用户可以注册登录。
- 管理员可以登录。
- 猫咪、求助领养、评论接口可查询数据库。
- 新增、编辑、删除操作真实写入数据库。
- 上传接口可保存本地文件并返回 URL。

## Phase 3：后台管理系统

### 目标

- 初始化 `admin/` Vue 3 + Vite 项目。
- 接入 Element Plus。
- 实现后台登录、布局、路由守卫。
- 实现 dashboard。
- 实现猫咪、求助领养、评论、用户、轮播图、基础配置管理。

### 验收

- 管理员可以登录后台。
- 401 自动退出登录。
- 每个列表页有 loading、empty、error、ready 状态。
- 后台新增、编辑、删除后数据库变化。
- 后台修改轮播图后，小程序首页接口返回变化。

## Phase 4：小程序基础框架

### 目标

- 初始化 `miniprogram/` 微信原生小程序结构。
- 配置 `app.json`、TabBar、全局样式。
- 封装 request、auth、config 工具。
- 接入静态素材。

### 验收

- 4 个 Tab 页面可切换。
- request 工具能调用后端。
- 登录态可保存、读取、清除。
- 静态素材路径可正常显示。

## Phase 5：小程序业务页面

### 目标

- 实现 11 个小程序页面。
- 接入首页、猫咪、求助领养、评论、我的相关接口。
- 发布求助领养支持最多 3 张图片。
- 评论功能在猫咪详情和求助领养详情中可用。

### 验收

- 未登录用户可浏览公开页面。
- 未登录用户发布或评论时跳转登录。
- 登录用户可发布求助领养。
- 登录用户可发表评论。
- 我的发布和我的评论可读取当前用户数据。

## Phase 6：联调与最终验收

### 目标

- 修复接口字段不一致。
- 补齐空状态、加载状态、错误提示。
- 更新 README 运行说明。
- 按 `docs/09-测试验收清单.md` 手工验收。

### 验收

- 数据库初始化后可完整跑通项目。
- 后端、后台、小程序能同时联调。
- 后台修改数据后，小程序展示同步变化。
- 最终交付包含小程序、后台、后端、数据库脚本和运行说明。
