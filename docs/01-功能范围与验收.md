# 01-功能范围与验收

本文件定义项目完成标准。后续每个开发阶段都必须对照本清单验收。

## 同学端验收

- [ ] 可以注册普通用户。
- [ ] 可以登录普通用户。
- [ ] 未登录可以浏览首页。
- [ ] 未登录可以浏览猫咪图鉴。
- [ ] 未登录可以浏览猫咪详情。
- [ ] 未登录可以浏览求助领养列表。
- [ ] 未登录可以浏览求助领养详情。
- [ ] 未登录点击发布入口时跳转登录页。
- [ ] 未登录点击“我的发布”时跳转登录页或提示登录。
- [ ] 未登录点击“我的评论”时跳转登录页或提示登录。
- [ ] 登录后可以发布求助领养信息。
- [ ] 登录后可以在猫咪详情发表评论。
- [ ] 登录后可以在求助领养详情发表评论。
- [ ] 登录后可以查看我的发布。
- [ ] 登录后可以查看我的评论。
- [ ] 登录后可以退出登录。

## 小程序页面范围

小程序同学端共 11 个页面：

1. 登录页。
2. 注册页。
3. 首页。
4. 猫咪图鉴列表页。
5. 猫咪详情页。
6. 求助领养列表页。
7. 求助领养详情页。
8. 发布求助领养页。
9. 我的页面。
10. 我的发布页。
11. 我的评论页。

“我的页面”包含未登录和已登录两种状态，但仍是同一个页面。

## 管理端验收

- [ ] 管理员可以登录后台。
- [ ] 管理员可以查看后台首页统计。
- [ ] 管理员可以新增猫咪。
- [ ] 管理员可以编辑猫咪。
- [ ] 管理员可以删除猫咪。
- [ ] 管理员可以新增求助领养信息。
- [ ] 管理员可以编辑求助领养信息。
- [ ] 管理员可以删除求助领养信息。
- [ ] 管理员可以修改求助领养状态。
- [ ] 管理员可以查看评论列表。
- [ ] 管理员可以删除评论。
- [ ] 管理员可以查看用户列表。
- [ ] 管理员可以编辑用户基础信息。
- [ ] 管理员可以删除用户。
- [ ] 管理员可以新增、编辑、删除首页轮播图。
- [ ] 管理员可以修改平台名称和首页文案。

## 数据验收

- [ ] 所有列表数据来自 MySQL。
- [ ] 所有详情数据来自 MySQL。
- [ ] 新增数据后数据库存在对应记录。
- [ ] 编辑数据后数据库记录同步变化。
- [ ] 删除数据后数据库记录被删除或被软删除标记。
- [ ] 后台修改轮播图后，小程序首页刷新能看到变化。
- [ ] 后台修改基础配置后，小程序首页展示随之变化。
- [ ] 用户发布求助领养后，小程序列表和数据库都能看到新记录。
- [ ] 用户发表评论后，详情页、我的评论、数据库都能看到新记录。

## 不在本项目范围

- [ ] 未执行真实微信授权。
- [ ] 未执行短信验证码。
- [ ] 未执行地图定位。
- [ ] 未执行在线支付。
- [ ] 未执行线上部署。
